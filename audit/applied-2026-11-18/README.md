# Архив применённых изменений Supabase

Это документация изменений, выполненных вручную пользователем в SQL Editor. Файлы НЕ подключены к CI, Supabase migrations или автоматическому развёртыванию. НЕ запускайте каталог повторно: CREATE TRIGGER/POLICY и ADD TABLE могут завершиться ошибкой. На новой базе без исходной схемы он не работает. Это не полный schema baseline и не резервная копия.

Скрипты реконструированы из подготовленных файлов и присланных результатов; форматирование может отличаться от истории SQL Editor. Значения пользовательских данных, секреты и ключи сюда не включены. checksums.json относится к архивным файлам, а не к объектам базы.

## Ограничения проверки

Свежий полный снимок функций, ACL, политик и триггеров после всех изменений не получен. Отдельное определение функции не доказывает все права и связанные политики. Synthetic-auth SQL не заменяет реальный JWT и второй аккаунт. Тестовый PostgreSQL был версии 16, production сообщил 17.6. Signed URL остаются действительны до истечения. Тесты реального чата между аккаунтами, мобильная доступность и удаление аккаунта не завершены.
